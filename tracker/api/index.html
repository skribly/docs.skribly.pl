Overview

Issue tracker of the Skribly ecosystem.

Skribly Tracker API 1.0.0

Section titled “Skribly Tracker API 1.0.0”

REST API v1 of Skribly Tracker. Authenticate with a personal access token created on the profile page (Authorization: Bearer <token>). Tokens carry the read ability and, for changing data, write. The guide at https://docs.skribly.pl/tracker/rest-api/ has curl examples.

Information

  • License: MIT
  • OpenAPI version: 3.1.0
