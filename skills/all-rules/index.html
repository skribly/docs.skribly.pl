All rules

Every rule of the agent-skills rule dictionary, by technology, with its severity, versions, line check and public source.

This page is generated from rules.json of agent-skills, so it says what the rule files say. The rule dictionary is in development and ships in the next release: 98 rules in 29 technologies, 58 of them with a line check that agent-skills rules --check runs on the project’s files. The rest are read by the agent while it works. How to list and check the rules: Rule dictionary.

Angular

Section titled “Angular”
Rule What it says Severity Versions Line check Source
angular/control-flow Templates use @if, @for with track and @switch, not *ngIf, *ngFor and ngSwitch. medium 17+ yes Angular, control flow migration
angular/signal-inputs New components take input(), output() and model() instead of @Input and @Output, one style per component. low 17.1+ no Angular, components
angular/standalone-default Angular 19 components are standalone without standalone: true; an NgModule-declared one says standalone: false. medium 19+ yes Angular, components
