    Skribly is a non-commercial learning project built in spare time by five developers from Rzeszów, Poland. It connects an issue tracker, a desktop environment for AI coding agents and a shared library of agent skills into one workflow. Each tool also works on its own.

    Status

    The product repositories are private for now and will open step by step. Pages that describe something not built yet say planned.

    The tools

    Section titled “The tools”

    • Skribly Agent

      A desktop app for macOS, Windows and Linux that runs Claude Code, Codex, Cursor Agent, Gemini CLI and nine more side by side, with tracker tasks, git, pipelines, skills, audits and a preview browser in one window.

    • agent-skills

      35 portable skills that take a coding agent from a tracker ticket to a reviewed, tested commit, with one installer for eight agents and no runtime dependencies.

    • Skribly Tracker

      An issue tracker in the browser: projects, issues with keys such as AGENT-12, Kanban boards, comments, time logs, signed webhooks and a REST API designed for agents.

    • Core

      @skribly/core holds the shared contracts, the Tracker client and webhook signing.

    • UI

      @skribly/ui holds the design tokens, the components and the site kit that give every app and every Skribly site the same look. Every component is live at ui.skribly.pl.
